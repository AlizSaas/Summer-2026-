Overview
Summer 2026 is a full‑stack personal productivity tracker for goals, projects, reading, and todos. It runs a React + Vite frontend on Cloudflare Workers, with a Hono API, tRPC for type‑safe calls, Better Auth for sessions, and D1 (SQLite) via Drizzle ORM. An AI assistant can answer questions and automate actions, and a Durable Object handles scheduled daily summary emails.

Key Features
Goals, projects, reading log, and kanban‑style todo board
Email/password auth with session management
Type‑safe API via tRPC
AI chat assistant for insights and automation
Daily summary emails scheduled via Durable Objects
Deployed on Cloudflare Workers + D1
Tech Stack
React, Vite, TanStack Router/Query, Hono, tRPC, Better Auth, Drizzle ORM, Cloudflare Workers/D1, Durable Objects, OpenAI APIs
